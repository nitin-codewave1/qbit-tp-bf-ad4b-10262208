# US-001-01: see a 'No proofs yet' empty state with one line of help text instead of a blank proofs table

## Definition

As a **New Prooflyt account owner with zero proofs**, I want to **see a 'No proofs yet' empty state with one line of help text instead of a blank proofs table**, so that **I know the list is empty by design and what to do next, so more zero-proof accounts reach the 'Upload your first proof' button (empty-state click-through KPI)**.

**Epic:** [[EP-001]]

## Acceptance Criteria
- [[AC-001-01-01]] — Given the proofs list has no items, when the user opens the proofs list, then the heading 'No proofs yet' and one line of help text are shown in place of the table
- [[AC-001-01-02]] — Given the proofs list has one or more items, when the user opens the proofs list, then the proofs table is shown and the empty state is not rendered
- [[AC-001-01-03]] — Given the empty state is displayed, when it renders, then its heading, help text and button use existing design tokens with no new styles
