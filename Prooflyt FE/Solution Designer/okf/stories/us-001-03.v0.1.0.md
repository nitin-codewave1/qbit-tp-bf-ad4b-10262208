# US-001-03

As a Prooflyt product designer, I want to have an illustration slot in the proofs empty state, so that artwork can be added later without changing the empty-state layout, keeping the call to action visible for the click-through KPI. - Given the proofs list has no items, when the empty state renders, then an illustration slot appears above the heading 'No proofs yet' - Given no illustration asset is available, when the empty state renders, then the illustration slot is still present and the heading, help text and button still display - Test case: the empty state renders - Test case: [edge] the empty state renders
